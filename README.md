## 📂 Repository Structure

The repository is organized to map directly to the weekly progression of the lab sessions[cite: 6]:

*   `📁 Lab-Manuals/` : Official lab instruction sheets and problem sets provided by the instructors.
*   `📁 Classworks/` : Code written during the live lab sessions in LIB602.
*   `📁 Homeworks/` : Submitted assignments and post-lab tasks.
*   `📁 Practice-Codes/` : Independent study scripts, including syntax tests and exercises from the book "Introduction to Java Programming and Data Structures, Comprehensive Version, 11th Global Edition by Y. Daniel Liang" and other sources.
*   `📁 Project/` : Final GUI/OOP application implementation (Added later in the semester).

## 🚀 Topics Covered

This lab supplements the CSE215 theory course by implementing the following Object-Oriented Programming (OOP) concepts in Java:

1.  **Procedural Review & Java Basics:** Primitive data types, operators, selection statements, and iterative loops.
2.  **Core OOP Principles:** Classes, objects, constructors, and encapsulation.
3.  **Advanced OOP Concepts:** Inheritance, polymorphism, abstract classes, and interfaces.
4.  **Data Structures:** 1D and multidimensional arrays, `String` manipulation, and generics.
5.  **Error Handling & I/O:** Exception handling and File Input/Output operations.
6.  **Advanced Java:** Multithreading, Event-driven programming, and GUI development.
